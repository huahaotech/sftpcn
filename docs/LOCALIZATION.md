# 中文文案规范

目标是让国内用户能看懂功能和后果，不以逐词对应英文为目标。

| 原文直译 | 当前用语 | 原因 |
| --- | --- | --- |
| 组 | 用户组 | 明确管理对象 |
| 活动连接 | 在线连接 | 说明这是当前在线会话 |
| 事件管理器 | 自动化任务 | 用任务解释触发规则与执行动作 |
| IP 管理器 | IP 访问控制 | 明确这是访问限制功能 |
| 服务器管理 | 系统管理 | 下级项采用系统设置、运行状态、备份与恢复 |
| 单目录权限 | 目录权限 | 简明且不损失含义 |
| 最大会话 | 最大同时连接数 | 说明限制的是并发连接 |
| 守护者 | 封禁与豁免规则 | 区分自动防护与账号白名单 |
| 最大令牌数 | 最多访问次数 | 分享的 token 在此代表使用次数 |
| 密钥前缀 | 对象路径前缀 | 对象存储 key 是对象路径，不是认证密钥 |
| 主目录 | 用户根目录 | 与 SFTP 客户端看到的根目录对应 |

“虚拟文件夹”保留，因为它表示额外存储挂载，不等于普通子目录或一律共享的文件夹。说明文案补充它与用户根目录的关系。

按钮采用动作短语，例如“新建用户”“确认删除”“立即执行”；错误提示说明发生了什么以及下一步怎么做。风险提示只描述真实后果，不把断开连接写成删除文件。

统一使用“账号”“用户组”“两步验证”“备用恢复码”“上传限速”。密码、动态验证码、加密口令、公钥与私钥分别表述，不混用。

`locale/editorial-overrides.json` 记录 476 项按语境改写的条目，`locale/zh.json` 是实际发布的完整语言文件。技术名称和变量占位符保留，自动检查键集合及插值变量一致性。
