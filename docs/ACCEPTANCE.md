# 部署验收

自动检查不代替真实服务器上的安全和连接验收。

1. 安装器完成后容器持续运行，`/healthz` 返回 200。
2. 浏览器打开后台，默认中文；可切换英文，重新登录与刷新不丢失偏好。
3. 首次设置要求随机初始化代码，不存在默认管理员密码。
4. 原有 SSH 22 端口仍可登录。
5. 创建两个不同根目录的测试账号，分别测试上传、下载与校验文件 SHA256。
6. 账号不能访问另一账号的文件，不能通过 `..` 走出虚拟根目录。
7. 从允许来源 IP 登录成功；从真实不同出口 IP 用正确密码登录失败。
8. 修改白名单并断开已有连接，验证新规则；禁用后不能重新登录。
9. SSH shell、任意命令执行和端口转发不可用。
10. 重启容器，账号、文件与主机密钥不变；备份并在独立测试环境恢复。

网站演示只用于展示操作流程，所有示例数据均为虚构，不代表测试已经完成。
