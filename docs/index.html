完整安装与使用说明 ↗
这是一个新的 SFTP 服务吗？

底层使用成熟的 SFTPGo 社区版。本项目整理 Ubuntu 部署流程和中文界面，固定匹配 SFTPGo 2.7.6，不重写文件传输协议。

会影响服务器原来的 SSH 登录吗？

默认不会。SFTP 使用 2022 端口，不修改原有 SSH 配置。原有 SSH 通常继续使用 22 端口。

删除账号会自动删掉文件吗？

附带的账号辅助工具删除账号时保留文件。文件清理由管理员备份后另行处理，重新使用同名目录前应核对归属。

直接通过 IP 访问，应该注意什么？

后台默认监听 8080，需在云安全组和防火墙放行。初始使用 HTTP；正式对公网使用时，应配置 HTTPS 或限制管理来源 IP。

这是官方的 SFTPGo 中文版吗？

不是官方发行版。SFTPCN 是独立的部署和本地化项目，上游版权、商标与许可条款保持有效。
