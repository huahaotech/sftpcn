02 / 从账号到资源，完整管理

文件服务需要的能力，
集中到一个地方。

给合作伙伴一个账号，也给它明确的权限。
既能满足日常交付，也能支撑持续的自动化传输。

01 / ACCOUNT
♧

账号与用户组

创建、编辑、禁用和删除传输账号。通过用户组统一分配设置，使用密码或 SSH 公钥验证身份。

虚拟用户 · 用户组 · 密码 / 公钥
02 / STORAGE
▱

独立目录与挂载

独立根目录 · 虚拟文件夹
03 / PERMISSION
⌘

按目录设置文件权限

上传、下载、覆盖、删除、改名和创建目录，分别授予所需权限。只收文件、只读下载，都能配置。

操作级授权 · 目录级控制
04 / ACCESS
◎

每个账号的 IP 白名单

指定允许登录的单个 IP 或网段，支持 IPv4 与 IPv6。账号凭据和来源限制一起控制访问。

单个 IP · CIDR 网段 · 自动封禁防护

▥

磁盘配额 · 传输配额 · 上传下载限速

开始前，你可能想了解

几个实际问题。

完整安装与使用说明 ↗
这是一个新的 SFTP 服务吗？

底层使用 SFTPGo Community 2.7.6，提供账号、目录、权限、配额、连接管理等能力。SFTPCN 将它整理为自带中文界面的 Ubuntu 部署方案，使用上游官方镜像。

会影响服务器原来的 SSH 登录吗？

默认不会。SFTP 使用 2022 端口，不修改原有 SSH 配置。原有 SSH 通常继续使用 22 端口。

删除账号会自动删掉文件吗？

附带的账号辅助工具删除账号时保留文件。文件清理由管理员备份后另行处理，重新使用同名目录前应核对归属。

直接通过 IP 访问，应该注意什么？

后台默认监听 8080。安装器会在已启用的 UFW 中自动放行服务端口，云安全组仍需单独配置。初始使用 HTTP；正式对公网使用时，应配置 HTTPS 或限制管理来源 IP。

用户会获得服务器的终端权限吗？

不会。传输账号是 SFTPGo 虚拟用户，不是 Linux 系统账号。默认配置禁用 SSH 命令，只提供文件传输。

所有扩展功能都已经开启了吗？

默认启用 SFTP 和管理后台，使用本地磁盘存储。对象存储、自动化通知及其他协议需要根据实际环境另行配置，详见上方能力范围。

这是官方的 SFTPGo 中文版吗？

不是官方发行版。SFTPCN 是独立的部署和本地化项目，上游版权、商标与许可条款保持有效。
